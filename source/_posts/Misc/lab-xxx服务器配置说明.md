# `xxx`服务器说明
> 个人配置记录，不足为外人道也，故隐去IP等，写为x

## ssh连接
用户**必须**在`labxxx`组中，才可以进行ssh连接，**推荐使用密钥连接方式**.

## 创建用户
在`/usr/local/etc/useradd.d`目录下，有创建用户的脚本，将新用户添加至`name.list`文件中，运行脚本即可，默认将用户加入管理员组和`labxxx`组中.

如果手动添加用户，**若需要ssh连接，请将用户附加到`labxxx`**.

## fail2ban
处于安全需求，引入此组件，可以一定程度上防止ssh爆破攻击，此组件会封禁持续尝试进行ssh连接的IP.

封禁配置在`/etc/fail2ban/jail.conf`中，简单修改了封禁规则的参数，如果**IP多次连接失败，会封禁**10min.

查看封禁状态：
```bash
sudo fail2ban-client status sshd
```

解除IP封禁：
```bash
sudo fail2ban-client set sshd unbanip 10.xx.xx.xx
```

# 关于重装系统

## 数据备份
一般情况下，重装系统只会导致系统盘数据丢失，所以外挂磁盘数据**理论**是可以保留，如果是物理磁盘，只需`umount`即可。但是对于`lvm`格式卷，一定需要注意逻辑卷组之间的联系，**尤其是要解除和系统盘之间的联系**，重装系统之后，恢复`lvm`的数据，可以上网搜索，大致指令应该是使用`pvscan`扫描恢复.

## BIOS
开机按`DEL`键，进入BIOS，使用启动盘重装系统.

## 网络配置
系统重装时，会要求配置网关。以下配置仅使用匿名占位符演示：

```conf
# 外网网卡
auto ens5f0
iface ens5f0 inet static
address xx.xx.xx.xx
netmask 255.255.255.0
gateway xx.xx.xx.254
# 内网网卡
auto ens7f1
iface ens7f1 inet static
address 10.x.x.x
netmask 255.255.0.0
```

最好也设置一下DNS服务器，比如`8.8.8.8/114.114.114.114`，以方便连接外网.

## 移除U盘重启
移除U盘重启后，可能在网络检查会花费一定时间，等待即可，最后，会停在`reached target...`，如果时间过长，按一下键盘，可能会有意外之喜.
